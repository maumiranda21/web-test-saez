# Saneamiento Ambiental EZ - Proyecto Web

Este paquete contiene la landing page rediseñada de Saneamiento Ambiental EZ, lista para ser desplegada mediante GitHub y Vercel.

## Instrucciones para el despliegue

1. Extrae todos los archivos de este ZIP en una carpeta en tu computadora.
2. Sube los archivos originales de imágenes solicitados a la carpeta `assets/img/`.

### Nomenclatura exacta de imágenes requeridas:
Debes colocar estas imágenes dentro de `assets/img/` para que la web funcione correctamente según lo programado:

- **Logotipo cabecera**: `src-saez-logo_default.png` (Con fondo transparente/positivo).
- **Logotipo pie de página**: `src-saez-logo_mono.png` (Versión monocromática/blanca transparente).
- **Icono libro reclamaciones**: `src-libro-reclamaciones-logo.png` (PNG transparente).
- **Fondo de la primera sección (Hero)**: `hero-bg.jpg` (Genera una imagen que transmita limpieza y seguridad).
- **Imagen para sección de servicios**: `servicios-placeholder.jpg` (Imagen en formato vertical o cuadrado sobre entornos limpios).
- **Imagen para sección de equipo/nosotros**: `equipo-placeholder.jpg` (Personal uniformado con equipo de protección).

### Subir a Vercel
1. Sube todo el código a un nuevo repositorio en **GitHub**.
2. Conecta ese repositorio a tu cuenta de **Vercel** (`New Project` -> `Import GitHub Repository`).
3. Vercel detectará automáticamente que es un sitio estático HTML/CSS/JS y lo desplegará sin configuraciones extras.
